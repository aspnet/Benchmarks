NET_RX softirq: where it runs
-----------------------------
The NIC (ens1f0np0, mlx5_core, 40 Gbit/s) has 56 receive queues, and /proc/irq/<n>/smp_affinity_list shows one completion-queue interrupt per queue, each pinned to a different single
logical CPU, covering all of 0-55 once. A cpuset of N CPUs therefore only contains N of the 56 queues' interrupts; the rest run on CPUs the process is not allowed on.
