Default-mode experiments on gold-lin, 2026-11-12 (evening)

Measured on crank (profile aspnet-gold-lin-relay), not independently reproduced.
Kestrel with the Bedrock registration, TCP HTTP/1.1 keep-alive, 1 KB response, wrk with 896 connections and 56 threads on a separate machine,
15 s measured, application limited to cores 0-27 (28 physical cores, hyper-thread siblings are cores 28-55 and are outside the cpuset).
One run per cell. Differences under about 5% are not findings.
NETWORKPROTO_DIAG=1 was set for every cell; the per-request figures come from analyze-diag.py (steady window, iowait counted as idle).
The full sampler output is in default-mode-experiments-diag.txt. The code of the experiments is in default-mode-experiments.patch (applies on aspnetcore 51af49adea).

Not measurable: connection:close on this load generator. Sockets default reached 10,599 requests per second with 896 socket errors,
a p99 of 44.7 ms and the load machine at 94.7% CPU, so the remaining close cells were stopped.

Machine topology (DIAG_TOPO): 1 package, 28 cores with 2 threads each (cpu i and i+28), one L3 shared by all 56 logical CPUs.

Sockets runs and the experiments ran about 10-40 minutes apart; the "% of Sockets" figures in Bedrock.md use the direct-sockets run (1,767,697).
